# keenspect.ai

Static site for Keenspect: a harness that runs a persistent fleet of Claude Code agents under controls built from real incidents.

- `index.html` and `style.css`: the whole site. No build step, no JavaScript, no trackers.
- `CNAME`: custom domain for GitHub Pages (`keenspect.ai`).

Served by GitHub Pages from the `main` branch, root folder. Open `index.html` in a browser to preview locally.

Related: [false-claim-ledger](https://github.com/keenspect-dev/false-claim-ledger), a runnable example of the ledger described on the site.
